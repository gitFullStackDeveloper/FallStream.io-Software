# FallStream.io Software

FallStream.io is a browser-based lecture and live session delivery platform that allows students to join lectures and live sessions directly through their web browser without installing additional software.

## Features

- Browser-based live lectures
- Live session delivery
- Direct browser access for students
- Lecture sharing
- Real-time communication
- YouTube-style live chat
- Responsive web interface

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Tailwind CSS
- **Backend:** Node.js
- **Database:** MongoDB
- **Desktop Integration:** Electron
